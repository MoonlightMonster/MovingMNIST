# 槽位交换根因精确定位（方案B2 实验副产品，2026-11-13）

本次"分段外推+反弹检测"实验虽证伪，但过程中产出了对**槽位交换根因**的关键新认知，推翻了两处旧结论。

## 一、反弹折叠证伪（方案B2）

| 方案 | ADE | FDE | 翻转准确率 |
|---|---|---|---|
| 不关联 | 5.25 | 7.28 | - |
| 方案B（直线外推） | **5.03** | 7.20 | 77.2% |
| 方案B2（反弹折叠） | 5.37 | 7.47 | 55.4% |

**结论**：反弹折叠画蛇添足。模型（ConvLSTM）本身已学会反弹，直线外推 ref 前5帧误差 6.05px 远优于折叠 ref 14.66px；末帧速度方向 83.5% 正确，仅 7.5% 立即反弹。网络外关联路线已逼近天花板。

## 二、交换根因的精确定位（新认知，推翻旧结论）

旧结论（误差分析_v4）：交换序列中 78% 发生在"跟踪过程"，87.9% 曾深度重叠。

新结论（本轮精确诊断）：

1. **锚定（当前帧=观测末帧）不交换**：误差仅 4.47px，与重叠无关（0/2000 交换）。
2. **47.3% 的交换序列在"未来第0帧"就交换**——即从观测末帧到未来首帧的**一步跳变**就接反。
3. 这 253 个"未来第0帧就交换"的序列里，**65.6% 在观测末帧时两数字已深度重叠（<14px）**。
4. **交换率与观测末帧重叠强相关**：距离 <14px → 45.5% 交换；≥28px → 仅 15.9%。

**核心结论**：交换的本质不是"跟踪中的漂移"，而是**"两数字在观测末帧已重叠，模型无法在重叠状态区分身份，从重叠分开时（未来首帧）轨迹随机接错"**。slot_feat 的 grid_sample 单点取样在重叠时取到的是两数字的混合像素，无法区分身份。

## 三、针对性增强：身份锚（slot_anchor）

基于根因，设计"身份锚"机制：解码器喂入**观测段"最清晰帧"（两数字间距最大）的身份外观特征**，在整个自回归解码中持续注入，让模型在重叠时"记住"而非"现场分辨"身份。

关键约束（吸取嵌入头/打包改动的教训）：
- 身份锚来自编码器 h1 取样，**坐标和特征全部 detach**，梯度不污染主任务。
- 观测段位置推理时可得（输入视频质心），训练用真值质心，**自洽且可部署**。
- 不改损失、不改 GAP 分类头、不改编码器，仅扩展解码器输入。

实现：`train_convlstm_v2.py` 新增 `--slot-anchor` 开关（默认关闭），`_load_weights_with_migration` 支持从 v4ft 宽松迁移权重（anchor_proj 随机初始化、cell 输入维扩大部分复制）。

## 四、待验证

从 v4ft 微调（tag=v5_anchor，cls_weight=3, lr=3e-4, 15ep），对照 v4ft 的 ADE 5.25/FDE 7.28/分类 96.5%。若身份锚有效，交换率应从 24.6% 下降。
