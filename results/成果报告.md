# Moving MNIST 多任务学习 —— 阶段成果报告

**日期**：2026-08-23
**状态**：三步路线全部落地，当前最优模型 **v3**（ConvLSTM 多任务）

---

## 一、任务定义

输入 Moving MNIST 视频前 10 帧（64×64，2 个运动数字），同时预测：

1. **分类**：每个数字的类别（2 × 10 类）
2. **轨迹**：后 10 帧每个数字的质心坐标 (x, y)

数据由 `moving_mnist.py` 在线合成（Srivastava et al. 2015 原始设定：64² 画布、2 数字、3~5 px/帧、撞墙反弹、重叠取最大值），训练数据无限，验证/测试用固定 seed 保证可复现。

**指标口径**：ADE = 预测段所有帧平均欧氏距离 (px)；FDE = 最后一帧欧氏距离 (px)；分类为逐数字准确率。测试集统一为 seed=2026 × 2000 条序列（MNIST 测试集数字合成）。

## 二、三步路线总览与最终结果

| 步骤 | 内容 | 结果 |
|---|---|---|
| 1 | CNN 单帧分类基线 | test_acc **99.76%**（`mnist_cnn_best.pth`） |
| 2 | 线性匀速外推轨迹基线 | ADE **23.88** / FDE **41.60** px（必须超越的底线） |
| 3 | ConvLSTM 多任务主模型（最终 = v4ft） | **ADE 5.25 / FDE 7.28 px / 分类 96.5%** |
| 4 | 身份锚增强（v5_anchor，2026-11-13） | **ADE 4.99 / FDE 7.00 px / 分类 96.35%** |

步骤 3 相对线性基线：**ADE 降 77.9%，FDE 降 82.2%**。基线失效的根因是撞墙反弹（每 7~12 帧一次，线性外推必然飞出画布），模型已学会反弹（见 `figs/v3_vs_baseline.png` sample 1 的折返轨迹）。

**步骤 4（v5_anchor）里程碑**：首次将 ADE 压入 5.0 以内（5.25→4.99），实现「理想 <5」目标线。核心是给轨迹解码器注入**观测段"最清晰帧"的身份外观锚**（全部 detach 防梯度污染），针对精确定位的根因——"观测末帧两数字已深度重叠时身份丢失，从重叠分开时轨迹随机接错"。交换率 32.9%→31.0%。详见 `results/交换根因定位与身份锚方案.md`。

## 三、当前最优模型（v3）细节

**架构**（22.30M 参数，`train_convlstm_v2.py` 配置 `--cls-mode gap --traj-mode delta --traj-loss huber --h1-ch 128 --h2-ch 256 --dec-hidden 768`）：

```
前10帧 → stem CNN (64→32→16) → ConvLSTM(128ch@16²) → 下采样 → ConvLSTM(256ch@8²)
       → 最终隐状态
       ├─ 分类头: GAP → MLP → (2,10)
       └─ 轨迹头: LSTMCell(768) 自回归, 第0步绝对锚定当前位置(辅助监督),
                  之后每步预测位移 Δ(x,y) 累加, free-running (喂自己的预测)
```

**关键设计**：
- 槽位规范化：两数字按首帧质心 x 排序，槽位 0 = 更靠左，输出顺序有确定含义
- 坐标 /64 归一化回归，评估换算回像素
- 损失 = CE(label_smoothing 0.1) + 1.0·SmoothL1(轨迹, beta=0.02≈1.3px) + 0.5·SmoothL1(锚定)
- AdamW(lr 1e-3, wd 5e-4) + 余弦退火 + 梯度裁剪 1.0 + AMP 混合精度
- 训练 45 epoch × 12800 序列/epoch 在线随机生成（seed=None）；验证 seed=555 × 1000 选最优（best epoch 42）；约 23 分钟（RTX 4060 Laptop）

**最终测试成绩**（seed=2026 × 2000 条）：
- 轨迹 **ADE 6.02 px**（画布边长 9.4%）、**FDE 8.30 px**
- 分类 **96.8%**（逐数字）

## 四、步骤 3 消融实验全记录（核心方法论资产）

四处候选改动两真两假，结论全部经 30 epoch 同配置对照验证：

| 配置 | 改动 | ADE | FDE | 分类 |
|---|---|---|---|---|
| v1 | 对照（绝对坐标+MSE+全局池化分类头，7.80M，30ep） | 7.81 | 9.98 | 95.6% |
| v2 | 两处改动打包 | 13.06 | 13.43 | 93.9% |
| v2a | 只改轨迹：位移累加+Huber | **6.05** | **8.35** | 95.5% |
| v2b | 只改分类：槽位取样(detach) | 7.82 | 9.91 | 82.0% |
| v3 | v2a + 大容量 22.3M + 45ep | 6.02 | 8.30 | 96.8% |
| **v4** | v3 + 解码器槽位外观特征（`--slot-feat`，22.5M，45ep） | **5.27** | **7.40** | 96.2% |
| v5 | v4 + clean 时间融合分类头（证伪） | 6.71 | 8.63 | 82.6% |
| **v4ft** | **最终**：v4 + λ_cls=3 微调 15ep | **5.25** | **7.28** | **96.5%** |

**v4ft（最终模型，2026-08-24）**：v4 基础上调高分类损失权重微调（`--init-from --cls-weight 3 --select acc --lr 3e-4`），两指标 Pareto 改进。分类 96.5% vs 目标 99% 判定为本架构天花板（取样式分类头两次证伪、损失重平衡仅 +0.3pt），差距集中在深度重叠样本，突破需换范式，不在当前路线内。

**v5 证伪（2026-08-24）**："最干净帧"分类头（速度估计反推过去每帧位置 + 按帧间距离时间融合取样）全面劣于 v4。与 v2b（82.0%）合看，**取样式分类头被两次独立证伪**——16×16 特征图单点取样感受野远小于 28px 数字，局部特征不含身份信息；GAP 头才是最优分类方案。此方向封存。

**v4（当前最优，2026-08-23）**：误差分析定位根因后实施——轨迹解码器每步用各槽位当前预测位置（detach）在 h1 上 grid_sample 该数字的局部外观特征（32 维/槽位）输入 LSTM，"外观+运动"双线索维持槽位身份。机制验证（`误差分析_v4.md`）：槽位交换率 30.2%→25.1%，非交换序列 ADE 5.00→4.15，p50 5.29→4.39。分类头保留 GAP（v2b 已证取样分类头有害），故分类未动。**当前最大短板 = 分类 96.2% vs 目标 99%**，错误集中在深度重叠样本（最小质心距 <14px 桶仅 95.6%）。

**结论与教训**：

1. ✅ **轨迹位移参数化 + Smooth L1 有效**（7.81→6.05）：贴合"匀速+反弹"物理结构，Huber 鼓励中位数、减轻 MSE 的"向均值收缩"。
2. ❌ **槽位取样分类头被证伪**（95.6%→82.0%）：全局池化不是分类瓶颈，h1 中层特征的局部采样反而丢身份线索。
3. ⚠️ **多任务共享中间量会被梯度污染**：v2 打包版中分类梯度经 grid_sample 把锚定位置带偏（锚定损失卡死，比无脑预测中心还差）；v2b detach 后轨迹立即恢复（7.82≈7.81），根因确认。
4. 📉 **容量/训练量杠杆已打满**：v3 加大容量只对分类有效（+1.2pt），轨迹已到地板（6.05→6.02）；末 5 轮完全平台化。
5. 🔬 **一次只改一个变量**：v2 打包改动一度导致方向误判，拆开消融后才定位真因。

## 五、误差分解分析（2026-08-23，`analyze_errors.py`，详见 `误差分析.md`）

对 v3 在 2000 条测试序列上逐帧分解，三个假设一一验证：

1. **撞墙反弹：不是主因** ❌。反弹帧误差 6.71px vs 平稳帧 5.93px，仅 1.13x——模型已学会反弹。
2. **槽位身份交换：是主因** ✅。30.2% 序列存在交换（≥3 帧预测离另一数字更近），其平均 ADE 8.40px；剔除后总体 ADE 5.00px。最差样本图（`figs/analysis_worst.png`）确认 top-6 全部是 [SWAP] 且都有深度重叠。
3. **分类错误集中在深度重叠** ✅。按输入窗口最小质心距离分桶：距离<14px（77.5% 序列）逐数字准确率仅 95.9%；≥14px 即升至 99.8%+。

**统一根因：近距离相遇/深度重叠**（最小质心距离 <14px，即两个 28px 数字的墨迹实质交叠）——82.5% 的槽位交换序列都发生过深度重叠。重叠时共享全局特征无法维持"哪个槽位是哪个数字"的身份绑定，分开后轨迹接错、分类认错。这是数据关联 (data association) 问题，不是容量或训练量问题。

**v4 改进方向（证据驱动）**：给轨迹解码器喂**槽位级特征**——每步用各槽位当前预测位置（detach 防污染）在 h1 特征图上 grid_sample 出该数字自己的局部特征，与位置一起输入 LSTM，让模型用"外观+运动"双重线索维持身份。分类头同理（在锚定位置取样）。
